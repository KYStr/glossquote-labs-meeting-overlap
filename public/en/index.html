Reading a window

A window includes its start and excludes its end. Both ends of the start range are valid, in whole minutes. Even the latest start leaves enough time to finish the meeting. 24:00 means the end of the selected day.

Common questions

Does this tool read calendars or send invitations?

No. Enter each person's availability yourself. The calculation runs in this page's memory; it does not read calendars or send invitations.

Can I combine times from different time zones?

No. Convert them yourself first so every entry uses the same time basis. This tool does not convert time zones or daylight saving time.

What happens when one person's intervals overlap or touch?

They are merged before the tool intersects that person's availability with every other participant's. Windows shorter than the meeting are omitted.

Can an interval end at 24:00?

Yes, as the end of a same-day interval only. A start cannot be 24:00, and intervals cannot cross midnight.

Will my draft remain if I leave this page?

No. The draft stays in the current page's memory and is cleared when you leave or switch languages. Returning starts with a blank workspace.
